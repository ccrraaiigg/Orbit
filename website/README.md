# Orbit

A livecoding pair-programming agent harness for Smalltalk in VSCode. It provides interactive remote access to Smalltalk, through Smalltalk's user interface, managed method execution, and a virtual filesystem.

## Getting Started

To get started, use the @orbit agent.

## Steering

The agent steering instructions are in `agents/orbit.agent.md`. Open them via the command palette ("Orbit: Open Steering") or the Get Started walkthrough.
